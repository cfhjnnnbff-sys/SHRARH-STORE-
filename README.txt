SHRARH STORE

المنتجات التي أكدها صاحب المتجر:
- 100 جوهرة فري فاير + 10 جواهر هدية: 10,500 جنيه سوداني.
- 60 شدة ببجي موبايل: 9,900 جنيه سوداني.

قبل النشر:
1) افتح script.js وأضف رقم واتساب عمل يديره ولي الأمر/شخص بالغ مسؤول، بصيغة دولية وأرقام فقط.
2) اختبر الأسعار والسلة والطلب.
3) تأكد من أن خدمات الشحن تتم عبر قنوات رسمية أو موثوقة، ولا تطلب كلمة مرور أو رمز تحقق من العميل.

النشر:
- يتطلب حساب GitHub وإذن صاحبه.
- بعد ربط GitHub، ارفع index.html وscript.js إلى مستودع، ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).
- انتظر حتى يظهر رابط GitHub Pages.

ملاحظة: هذه نسخة متجر ثابتة أولية، وليست نظام دفع إلكتروني أو لوحة إدارة وقاعدة بيانات.
